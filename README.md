# Heroes Python

A minimal skeleton for a Heroes of Might and Magic style game built with Python and Pygame.

## Requirements

- Python 3.8+
- [Pygame](https://www.pygame.org/)

Install dependencies with:

```bash
pip install pygame
```

## Running the Game

```bash
python main.py
```

This will open a simple grid where you can move the hero using the arrow keys. The project is only a starting point and can be extended with additional gameplay mechanics.
